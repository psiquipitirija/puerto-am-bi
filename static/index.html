Cómo editar el Excel y refrescar el dashboard
  1. Abre data/Puerto_AM_Base_Datos_DEMO.xlsx en Excel.
  2. Modifica cantidades, precios o costos en la hoja Ventas y guarda (Ctrl + S).
  3. Vuelve al dashboard y pulsa Actualizar datos en la barra superior.
  4. Los KPIs, gráficos y la tabla se recalculan desde el archivo guardado.
